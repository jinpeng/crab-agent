# M0+M1（脊椎）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 搭起 workspace 骨架（M0），并做出无网络无终端的核心：领域类型、SSE 状态机、session JSONL 读写、loop 与 abort 语义、MockProvider（M1）。

**Architecture:** workspace 两 crate。`crab-core` 内禁止终端依赖与 `println!`（Q19）。SSE 解析是不碰 IO 的纯函数状态机（Q13）。session 是 append-only JSONL、entry 带 `id`/`parent_id`、v0 只线性追加 + `--continue`（Q8）。abort 时已产生的内容必须落盘（Q11）。

**Tech Stack:** Rust edition 2024 / cargo 1.98.1。tokio 1.53、serde 1、serde_json 1、thiserror 2、anyhow 1、tokio-util 0.7（CancellationToken）。本机 cargo 需代理访问 crates.io。

**本计划范围：** M0（任务 1-3）+ M1（任务 4-11）。M2 工具层、M3 真 provider、M4 CLI 各自单独出计划。

**本计划的完成标志（DESIGN.md §12 M1）：** `cargo test` 证明"多轮 + tool 调用 + 工具报错 + abort 后状态可恢复"全部成立，且 `crab-core` 里无 `reqwest`/`crossterm`/`println!`。

```rust
use crate::types::{EntryId, Message};
use serde::{Deserialize, Serialize};
use std::io::Write;
use std::path::{Path, PathBuf};

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum SessionEntry {
    Message { id: EntryId, parent_id: Option<EntryId>, message: Message },
}

pub struct Session {
    path: PathBuf,
    entries: Vec<SessionEntry>,
    next_id: EntryId,
}

impl Session {
    /// 在 dir 下新建唯一 session 文件（名 = 时间戳纳秒），返回 Session。
    pub fn create(dir: &Path) -> std::io::Result<Self> {
        std::fs::create_dir_all(dir)?;
        let nanos = std::time::SystemTime::now()
            .duration_since(std::time::UNIX_EPOCH).map(|d| d.as_nanos()).unwrap_or(0);
        let path = dir.join(format!("session-{nanos}.jsonl"));
        std::fs::File::create(&path)?;
        Ok(Self { path, entries: Vec::new(), next_id: 0 })
    }

    pub fn path(&self) -> &Path { &self.path }
    pub fn entries(&self) -> &[SessionEntry] { &self.entries }

    pub fn append(&mut self, message: Message) -> std::io::Result<EntryId> {
        let id = self.next_id;
        let parent_id = self.entries.last().map(|e| e.id());
        let entry = SessionEntry::Message { id, parent_id, message };
        let mut f = std::fs::OpenOptions::new().append(true).open(&self.path)?;
        writeln!(f, "{}", serde_json::to_string(&entry).map_err(std::io::Error::other)?)?;
        self.entries.push(entry);
        self.next_id += 1;
        Ok(id)
    }
}

impl SessionEntry {
    pub fn id(&self) -> EntryId {
        match self { SessionEntry::Message { id, .. } => *id }
    }
}
```

```rust
    /// 从 JSONL 文件重建（供 --continue）。逐行解析，任一坏行报错。
    pub fn load(path: &Path) -> std::io::Result<Self> {
        let raw = std::fs::read_to_string(path)?;
        let mut entries = Vec::new();
        let mut max_id = None::<EntryId>;
        for (n, line) in raw.lines().enumerate() {
            if line.trim().is_empty() { continue; }
            let entry: SessionEntry = serde_json::from_str(line)
                .map_err(|e| std::io::Error::new(std::io::ErrorKind::InvalidData,
                    format!("{}:{}: {}", path.display(), n + 1, e)))?;
            max_id = Some(max_id.map_or(entry.id(), |m: EntryId| m.max(entry.id())));
            entries.push(entry);
        }
        Ok(Self {
            path: path.to_path_buf(),
            next_id: max_id.map(|m| m + 1).unwrap_or(0),
            entries,
        })
    }

    pub fn next_id(&self) -> EntryId { self.next_id }
```

```rust
pub enum StreamEvent {
    TextDelta(String),
    ToolUseStart { index: usize, id: ToolCallId, name: String },
    ToolInputDelta { index: usize, json_fragment: String },
    ToolUseEnd { index: usize },
    StreamEnd { reason: StopReason },
}

struct ToolSlot {
    id: ToolCallId,
    name: String,
    json_buf: String,
}

/// 把流式事件组装成 AssistantTurn。纯函数状态机，不碰 IO（Q13）。
/// 槽位按 index 建；同一 index 的 delta 追加；arguments 收全后才解析。
pub struct StreamAccumulator {
    text: String,
    /// (index, slot)，按 index 升序，保证输出顺序稳定。
    slots: Vec<(usize, ToolSlot)>,
    stop: StopReason,
}

impl StreamAccumulator {
    pub fn new() -> Self {
        Self { text: String::new(), slots: Vec::new(), stop: StopReason::EndTurn }
    }

    pub fn push(&mut self, ev: StreamEvent) {
        match ev {
            StreamEvent::TextDelta(s) => self.text.push_str(&s),
            StreamEvent::ToolUseStart { index, id, name } => {
                self.slots.push((index, ToolSlot { id, name, json_buf: String::new() }));
            }
            StreamEvent::ToolInputDelta { index, json_fragment } => {
                if let Some((_, slot)) = self.slot_mut(index) {
                    slot.json_buf.push_str(&json_fragment);
                }
            }
            StreamEvent::ToolUseEnd { .. } => {}
            StreamEvent::StreamEnd { reason } => self.stop = reason,
        }
    }

    fn slot_mut(&mut self, index: usize) -> Option<&mut (usize, ToolSlot)> {
        // 先按 index 精确找；找不到则退化为"追加到最后一个槽"（缺 index 的 provider，Q13）。
        self.slots.iter_mut().find(|(i, _)| *i == index)
            .or_else(|| self.slots.last_mut())
    }

    pub fn finish(mut self) -> AssistantTurn {
        self.slots.sort_by_key(|(i, _)| *i);
        let mut content = Vec::new();
        if !self.text.is_empty() {
            content.push(ContentBlock::Text { text: std::mem::take(&mut self.text) });
        }
        for (_, slot) in self.slots {
            match serde_json::from_str::<serde_json::Value>(&slot.json_buf) {
                Ok(input) => content.push(ContentBlock::ToolUse { id: slot.id, name: slot.name, input }),
                // 解析失败：原始字符串作为错误 ToolResult 回灌，让模型重试。
                Err(e) => content.push(ContentBlock::ToolResult {
                    tool_use_id: slot.id,
                    content: format!("invalid tool arguments JSON: {e}. raw: {}", slot.json_buf),
                    is_error: true,
                }),
            }
        }
        let interrupted = matches!(self.stop, StopReason::Aborted | StopReason::Error);
        AssistantTurn {
            message: Message { role: Role::Assistant, content },
            stop_reason: self.stop,
            interrupted,
        }
    }
}

impl Default for StreamAccumulator { fn default() -> Self { Self::new() } }
```

```rust
pub trait Tool: Send + Sync {

    async fn execute(&self, args: serde_json::Value) -> Result<String, ToolError>;
```

```rust
use crate::provider::{Provider, ProviderError};
use crate::session::Session;
use crate::tool::ToolRegistry;
use crate::types::{ContentBlock, EntryId, Message, Role, StopReason};

#[derive(Debug)]
pub struct AgentConfig { pub max_turns: usize }

#[derive(Debug, thiserror::Error)]
pub enum AgentError {
    #[error("provider: {0}")]
    Provider(#[from] ProviderError),
    #[error("io: {0}")]
    Io(#[from] std::io::Error),
    #[error("exceeded max_turns {0}")]
    MaxTurns(usize),
}

#[derive(Debug, Clone, PartialEq)]
pub enum AgentEvent {
    TurnStarted { turn: usize },
    TextDelta(String),
    AssistantMessage(Message),
    ToolCallStarted { id: crate::types::ToolCallId, name: String },
    ToolCallFinished { id: crate::types::ToolCallId, result: String, is_error: bool },
    Finished { reason: StopReason },
}

pub struct Agent {
    provider: Box<dyn Provider>,
    tools: ToolRegistry,
    session: Session,
    config: AgentConfig,
    /// 内存中的会话历史（含本轮产生的），run 结束时与 session 一致。
    history: Vec<Message>,
    abort: tokio_util::sync::CancellationToken,
    events_tx: tokio::sync::broadcast::Sender<AgentEvent>,
    provider_calls: Vec<Vec<Message>>,
}

impl Agent {
    pub fn new(
        provider: Box<dyn Provider>,
        tools: ToolRegistry,
        session: Session,
        config: AgentConfig,
    ) -> Self {
        let (events_tx, _) = tokio::sync::broadcast::channel(64);
        Self {
            provider, tools, session, config,
            history: Vec::new(),
            abort: tokio_util::sync::CancellationToken::new(),
            events_tx,
            provider_calls: Vec::new(),
        }
    }

    pub fn subscribe(&self) -> tokio::sync::broadcast::Receiver<AgentEvent> {
        self.events_tx.subscribe()
    }
    pub fn abort(&self) { self.abort.cancel(); }
    pub fn provider_calls(&self) -> &[Vec<Message>] { &self.provider_calls }
    pub fn history(&self) -> &[Message] { &self.history }

    pub async fn run(&mut self, user_input: String) -> Result<StopReason, AgentError> {
        let user = Message { role: Role::User,
            content: vec![ContentBlock::Text { text: user_input }] };
        self.push_and_record(user.clone());
        self.history.push(user);

        for turn in 0..self.config.max_turns {
            if self.abort.is_cancelled() {
                let _ = self.events_tx.send(AgentEvent::Finished { reason: StopReason::Aborted });
                return Ok(StopReason::Aborted);
            }
            let _ = self.events_tx.send(AgentEvent::TurnStarted { turn });

            self.provider_calls.push(self.history.clone());
            let t = self.provider.complete(&self.history).await?;
            let msg = t.message.clone();
            let _ = self.events_tx.send(AgentEvent::AssistantMessage(msg.clone()));
            self.push_and_record(msg.clone());
            self.history.push(msg.clone());

            if t.stop_reason != StopReason::ToolUse {
                let _ = self.events_tx.send(AgentEvent::Finished { reason: t.stop_reason });
                return Ok(t.stop_reason);
            }

            // 执行本轮所有 tool_use，结果回灌
            let mut results: Vec<ContentBlock> = Vec::new();
            for block in &msg.content {
                if let ContentBlock::ToolUse { id, name, input } = block {
                    let _ = self.events_tx.send(AgentEvent::ToolCallStarted { id: id.clone(), name: name.clone() });
                    let (content, is_error) = match self.tools.execute(name, input.clone()).await {
                        Ok(r) => (r, false),
                        Err(e) => (e.to_string(), true),
                    };
                    let _ = self.events_tx.send(AgentEvent::ToolCallFinished {
                        id: id.clone(), result: content.clone(), is_error });
                    results.push(ContentBlock::ToolResult {
                        tool_use_id: id.clone(), content, is_error });
                }
            }
            let tool_result_msg = Message { role: Role::User, content: results };
            self.push_and_record(tool_result_msg.clone());
            self.history.push(tool_result_msg);
        }
        Err(AgentError::MaxTurns(self.config.max_turns))
    }

    fn push_and_record(&mut self, m: Message) {
        let _ = self.session.append(m);
    }

    // 测试辅助：在 MockProvider 之外记录每次 complete 的入参
    #[allow(dead_code)]
    fn record_calls(&mut self, m: Vec<Message>) { self.provider_calls.push(m); }
}

// 让测试能拿到 EntryId 而不暴露内部
impl Agent {
    pub fn session_entries(&self) -> &[crate::session::SessionEntry] { self.session.entries() }
    pub fn last_entry_id(&self) -> Option<EntryId> {
        self.session.entries().last().map(|e| e.id())
    }
}
```
