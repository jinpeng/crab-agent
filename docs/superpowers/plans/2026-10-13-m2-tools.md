# M2 工具层 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 v0 全部 6 个工具（`read`/`write`/`edit`/`bash`/`glob`/`grep`）+ 支撑它们的 `SessionState`（新鲜度门禁）与 `PermissionGate`（权限门禁），全部落在 `crab-core`，零终端依赖。

**Architecture:** 工具实现 `M1` 的 `Tool` trait（`execute(&self, args)`），共享状态靠 `Arc<Mutex<>>` 注入（因 `&self` 签名）。`edit`/`write` 用 tempfile 同目录原子 rename 落地"全有全无"（DESIGN §5）。`bash` 用 `kill_on_drop(true)` + 超时 + 头尾截断。权限确认走 trait 回调，v0 core 只给 AutoApprove/AutoDeny，交互确认留 M4。

**Tech Stack:** tokio `process`/`fs`、`tempfile`（原子写 + 测试）、`globset`、`grep-searcher`/`grep-regex`、`similar`（仅报错提示）、`shell-words`（bash 门禁分类的词法切分）。新增依赖见 Task 0。

**前置状态（已存在，勿重建）：** `crab-core` 有 `Tool`/`ToolError`/`ToolRegistry`（tool.rs）、`Agent`（agent.rs，通过 `ToolRegistry::execute` 调工具）。`crab-core` 红线：无终端/网络 crate、无 `println!`。本机 cargo 需代理 `export https_proxy=http://127.0.0.1:10808`。

## 共享状态契约（后续所有工具任务共用，先读这个）

```rust
// crates/crab-core/src/state.rs
use std::collections::{HashMap, HashSet};
use std::path::PathBuf;
use std::sync::{Arc, Mutex};
use std::time::SystemTime;

/// 跨工具共享的会话状态：本会话读过哪些文件、读时的 mtime。
/// edit/write 的新鲜度门禁据此判断"模型看到的是不是过期内容"（Q14）。
#[derive(Clone, Default)]
pub struct SessionState {
    inner: Arc<Mutex<HashMap<PathBuf, SystemTime>>>,
}

impl SessionState {
    /// read 工具调用后记录：path 在 mtime 时刻被读过。
    pub fn mark_read(&self, path: PathBuf, mtime: SystemTime);
    /// 新鲜度判定：读过且磁盘 mtime 仍等于读时的 mtime。
    pub fn is_fresh(&self, path: &std::path::Path) -> bool;
}
```

```rust
// crates/crab-core/src/gate.rs
use std::sync::Arc;

/// 一次待确认的危险操作。
#[derive(Debug, Clone)]
pub struct Prompt {
    pub tool: &'static str,
    pub summary: String,      // 人类可读：要干什么（如 "write to /etc/hosts"）
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Decision { Allow, Deny, AllowAll }  // AllowAll = 会话内"本次全放行"

pub type Confirmer = Arc<dyn Fn(Prompt) -> Decision + Send + Sync>;

/// 权限门禁（Q9）：读类放行，写/网/删类经 confirmer 确认。
/// 明确不是安全边界——见 DESIGN §6。
#[derive(Clone)]
pub struct PermissionGate {
    confirmer: Confirmer,
    yolo: bool,
    allow_all: std::sync::Arc<std::sync::atomic::AtomicBool>,
}

impl PermissionGate {
    pub fn yolo() -> Self;                       // --yolo：全放行
    pub fn auto_approve() -> Self;               // 测试/非交互：全放行
    pub fn auto_deny() -> Self;                  // 测试：全拒
    pub fn with_confirmer(c: Confirmer) -> Self; // M4 接交互确认
    /// 危险操作走这里。返回 Err 表示被拒。
    pub fn check(&self, p: Prompt) -> Result<(), crate::tool::ToolError>;
}
```

**工具构造约定**：需要门禁的工具持有 `PermissionGate`；`read`/`edit`/`write` 持有 `SessionState`。通过 `Arc` 共享，registry 里各工具拿到同一份。

```rust
use std::collections::HashMap;
use std::path::{Path, PathBuf};
use std::sync::{Arc, Mutex};
use std::time::SystemTime;

#[derive(Clone, Default)]
pub struct SessionState {
    inner: Arc<Mutex<HashMap<PathBuf, SystemTime>>>,
}

impl SessionState {
    pub fn mark_read(&self, path: PathBuf, mtime: SystemTime) {
        self.inner.lock().unwrap().insert(path, mtime);
    }

    pub fn is_fresh(&self, path: &Path) -> bool {
        let recorded = match self.inner.lock().unwrap().get(path) {
            Some(m) => *m,
            None => return false,
        };
        match std::fs::metadata(path).and_then(|md| md.modified()) {
            Ok(current) => current == recorded,
            Err(_) => false,   // 文件没了 = 不新鲜
        }
    }
}
```

```rust
use crate::tool::ToolError;
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Arc;

#[derive(Debug, Clone)]
pub struct Prompt {
    pub tool: &'static str,
    pub summary: String,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Decision {
    Allow,
    Deny,
    AllowAll,
}

pub type Confirmer = Arc<dyn Fn(Prompt) -> Decision + Send + Sync>;

#[derive(Clone)]
pub struct PermissionGate {
    confirmer: Confirmer,
    yolo: bool,
    allow_all: Arc<AtomicBool>,
}

impl PermissionGate {
    pub fn yolo() -> Self {
        Self { confirmer: Arc::new(|_| Decision::Allow), yolo: true, allow_all: Arc::new(AtomicBool::new(true)) }
    }
    pub fn auto_approve() -> Self {
        Self { confirmer: Arc::new(|_| Decision::Allow), yolo: false, allow_all: Arc::new(AtomicBool::new(false)) }
    }
    pub fn auto_deny() -> Self {
        Self { confirmer: Arc::new(|_| Decision::Deny), yolo: false, allow_all: Arc::new(AtomicBool::new(false)) }
    }
    pub fn with_confirmer(c: Confirmer) -> Self {
        Self { confirmer: c, yolo: false, allow_all: Arc::new(AtomicBool::new(false)) }
    }

    pub fn check(&self, p: Prompt) -> Result<(), ToolError> {
        if self.yolo || self.allow_all.load(Ordering::SeqCst) {
            return Ok(());
        }
        match (self.confirmer)(p.clone()) {
            Decision::Allow => Ok(()),
            Decision::AllowAll => {
                self.allow_all.store(true, Ordering::SeqCst);
                Ok(())
            }
            Decision::Deny => Err(ToolError::Exec(format!(
                "permission denied: {} ({})",
                p.summary, p.tool
            ))),
        }
    }
}
```

```rust
use crate::state::SessionState;
use crate::tool::{Tool, ToolError};
use async_trait::async_trait;
use std::path::PathBuf;

const MAX_BYTES: usize = 100_000;

pub struct ReadTool {
    state: SessionState,
}

impl ReadTool {
    pub fn new(state: SessionState) -> Self {
        Self { state }
    }
}

#[async_trait]
impl Tool for ReadTool {
    fn name(&self) -> &'static str { "read" }
    fn description(&self) -> &'static str {
        "Read a UTF-8 text file. Returns contents (truncated past 100KB with a notice). Records the file as read for the freshness gate, so edit/write can detect external changes."
    }
    fn schema(&self) -> serde_json::Value {
        serde_json::json!({
            "type": "object",
            "properties": { "path": { "type": "string", "description": "absolute or cwd-relative path" } },
            "required": ["path"]
        })
    }
    async fn execute(&self, args: serde_json::Value) -> Result<String, ToolError> {
        let path = args["path"].as_str()
            .ok_or_else(|| ToolError::InvalidArgs("missing 'path' string".into()))?;
        let bytes = tokio::fs::read(path).await
            .map_err(|e| ToolError::Exec(format!("read {path}: {e}")))?;
        let mtime = std::fs::metadata(path).and_then(|m| m.modified())
            .map_err(|e| ToolError::Exec(format!("stat {path}: {e}")))?;
        self.state.mark_read(PathBuf::from(path), mtime);

        let text = String::from_utf8_lossy(&bytes);
        if text.len() > MAX_BYTES {
            let keep = &text[..MAX_BYTES];
            Ok(format!("{keep}\n... [truncated {} bytes]", text.len() - MAX_BYTES))
        } else {
            Ok(text.into_owned())
        }
    }
}
```

- [ ] **Step 3: 实现**——关键：覆盖已存在文件时先查 `state.is_fresh`（除非文件不存在=新建）；门禁 `check`；**原子写**：`tempfile::NamedTempFile::new_in(父目录)` 写入后 `persist(path)`

```rust
use crate::gate::{PermissionGate, Prompt};
use crate::state::SessionState;
use crate::tool::{Tool, ToolError};
use async_trait::async_trait;
use std::path::{Path, PathBuf};

pub struct WriteTool {
    state: SessionState,
    gate: PermissionGate,
}

impl WriteTool {
    pub fn new(state: SessionState, gate: PermissionGate) -> Self {
        Self { state, gate }
    }

    /// 原子写：同目录临时文件写满后 rename，崩溃不留半个文件（DESIGN §5 全有全无）。
    fn atomic_write(path: &Path, content: &str) -> std::io::Result<()> {
        let dir = path.parent().unwrap_or_else(|| Path::new("."));
        let mut tmp = tempfile::NamedTempFile::new_in(dir)?;
        std::io::Write::write_all(&mut tmp, content.as_bytes())?;
        tmp.persist(path).map_err(|e| e.error)?;
        Ok(())
    }
}

#[async_trait]
impl Tool for WriteTool {
    fn name(&self) -> &'static str { "write" }
    fn description(&self) -> &'static str {
        "Write a file (created if missing, overwritten if present). Overwriting requires the file was read this session and is unchanged since (freshness gate). Writes are atomic."
    }
    fn schema(&self) -> serde_json::Value {
        serde_json::json!({
            "type": "object",
            "properties": {
                "path": { "type": "string" },
                "content": { "type": "string" }
            },
            "required": ["path", "content"]
        })
    }
    async fn execute(&self, args: serde_json::Value) -> Result<String, ToolError> {
        let path = args["path"].as_str()
            .ok_or_else(|| ToolError::InvalidArgs("missing 'path'".into()))?;
        let content = args["content"].as_str()
            .ok_or_else(|| ToolError::InvalidArgs("missing 'content'".into()))?;
        let p = PathBuf::from(path);

        if p.exists() && !self.state.is_fresh(&p) {
            return Err(ToolError::Exec(format!(
                "refusing to overwrite {path}: not read this session or changed externally. read it first"
            )));
        }
        self.gate.check(Prompt { tool: "write", summary: format!("write {path}") })?;
        Self::atomic_write(&p, content)
            .map_err(|e| ToolError::Exec(format!("write {path}: {e}")))?;
        // 写完即新鲜（内容是我们刚写的）
        if let Ok(m) = std::fs::metadata(&p).and_then(|md| md.modified()) {
            self.state.mark_read(p, m);
        }
        Ok(format!("wrote {} bytes to {path}", content.len()))
    }
}
```

```rust
use crate::tool::ToolError;

#[derive(Debug, Clone)]
pub struct Edit {
    pub old: String,
    pub new: String,
}

#[derive(Debug, thiserror::Error, PartialEq)]
pub enum EditError {
    #[error("no match for old text. closest: {0}")]
    NoMatch(String),
    #[error("old text matches {count} times (must be unique). first at byte {first_byte}")]
    NotUnique { count: usize, first_byte: usize },
    #[error("edits overlap")]
    Overlap,
}

/// 对 content 应用多处 edit。所有 oldText 对**原文**匹配、各要求唯一、互不重叠。
/// 全有全无：任一失败则整体 Err，不返回部分结果。
pub fn apply_edits(content: &str, edits: &[Edit]) -> Result<String, EditError> {
    // 1. 为每个 edit 找所有匹配位置，要求唯一
    let mut spans: Vec<(usize, usize, &str)> = Vec::new(); // (start, end, new)
    for e in edits {
        let matches: Vec<usize> = content.match_indices(&e.old).map(|(i, _)| i).collect();
        match matches.len() {
            0 => return Err(EditError::NoMatch(closest_hint(content, &e.old))),
            1 => spans.push((matches[0], matches[0] + e.old.len(), &e.new)),
            n => return Err(EditError::NotUnique { count: n, first_byte: matches[0] }),
        }
    }
    // 2. 按 start 排序，检查重叠
    spans.sort_by_key(|(s, _, _)| *s);
    for w in spans.windows(2) {
        if w[0].1 > w[1].0 {
            return Err(EditError::Overlap);
        }
    }
    // 3. 从后往前替换（保证前面的 byte 偏移不失效）
    let mut out = content.to_string();
    for (start, end, new) in spans.iter().rev() {
        out.replace_range(*start..*end, new);
    }
    Ok(out)
}

/// similar 只用于生成报错提示，绝不用于决定改哪里（Q14）。
fn closest_hint(content: &str, needle: &str) -> String {
    let mut best = (0.0f64, "");
    for line in content.lines() {
        let r = similar::TextDiff::from_chars(needle, line).ratio();
        if r > best.0 {
            best = (r, line);
        }
    }
    if best.0 > 0.3 {
        format!("nearest line (similarity {:.0}%): `{}`", best.0 * 100.0, best.1.trim())
    } else {
        "no similar line found".into()
    }
}
```

```rust
// 追加到 edit.rs（在 apply_edits 之下）
use crate::gate::{PermissionGate, Prompt};
use crate::state::SessionState;
use crate::tool::{Tool, ToolError};
use async_trait::async_trait;
use std::path::PathBuf;

pub struct EditTool {
    state: SessionState,
    gate: PermissionGate,
}

impl EditTool {
    pub fn new(state: SessionState, gate: PermissionGate) -> Self {
        Self { state, gate }
    }
}

#[async_trait]
impl Tool for EditTool {
    fn name(&self) -> &'static str { "edit" }
    fn description(&self) -> &'static str {
        "Apply exact-match edits to a file. Each edit's `old` must match the file EXACTLY once (literal, no whitespace tolerance) and edits must not overlap; all edits match against the original content and apply atomically (all-or-nothing). The file must have been read this session and be unchanged since."
    }
    fn schema(&self) -> serde_json::Value {
        serde_json::json!({
            "type": "object",
            "properties": {
                "path": { "type": "string" },
                "edits": {
                    "type": "array",
                    "items": {
                        "type": "object",
                        "properties": {
                            "old": { "type": "string", "description": "exact text, must match uniquely" },
                            "new": { "type": "string", "description": "replacement" }
                        },
                        "required": ["old", "new"]
                    }
                }
            },
            "required": ["path", "edits"]
        })
    }
    async fn execute(&self, args: serde_json::Value) -> Result<String, ToolError> {
        let path = args["path"].as_str()
            .ok_or_else(|| ToolError::InvalidArgs("missing 'path'".into()))?;
        let p = PathBuf::from(path);
        let edits: Vec<Edit> = serde_json::from_value(args["edits"].clone())
            .map_err(|e| ToolError::InvalidArgs(format!("bad 'edits': {e}")))?;
        if edits.is_empty() {
            return Err(ToolError::InvalidArgs("'edits' must be non-empty".into()));
        }

        if !self.state.is_fresh(&p) {
            return Err(ToolError::Exec(format!(
                "refusing to edit {path}: not read this session or changed externally. read it first"
            )));
        }
        let original = tokio::fs::read_to_string(&p).await
            .map_err(|e| ToolError::Exec(format!("read {path}: {e}")))?;
        let updated = apply_edits(&original, &edits)
            .map_err(|e| ToolError::Exec(e.to_string()))?;

        self.gate.check(Prompt { tool: "edit", summary: format!("edit {path} ({} edit(s))", edits.len()) })?;

        // 原子写
        let dir = p.parent().unwrap_or_else(|| std::path::Path::new("."));
        let mut tmp = tempfile::NamedTempFile::new_in(dir)
            .map_err(|e| ToolError::Exec(e.to_string()))?;
        std::io::Write::write_all(&mut tmp, updated.as_bytes())
            .map_err(|e| ToolError::Exec(e.to_string()))?;
        tmp.persist(&p).map_err(|e| ToolError::Exec(e.error.to_string()))?;

        if let Ok(m) = std::fs::metadata(&p).and_then(|md| md.modified()) {
            self.state.mark_read(p, m);
        }
        Ok(format!("applied {} edit(s) to {path}", edits.len()))
    }
}
```

```rust
use crate::tool::{Tool, ToolError};
use async_trait::async_trait;
use globset::{Glob, GlobMatcher};
use std::path::Path;

pub struct GlobTool;

impl GlobTool {
    pub fn new() -> Self { Self }

    fn walk(root: &Path, matcher: &GlobMatcher, out: &mut Vec<String>) -> std::io::Result<()> {
        for entry in std::fs::read_dir(root)? {
            let entry = entry?;
            let path = entry.path();
            let rel = path.strip_prefix(root).unwrap_or(&path);
            if path.is_dir() {
                Self::walk(&path, matcher, out)?;
            } else if matcher.is_match(rel) {
                out.push(rel.to_string_lossy().into_owned());
            }
        }
        Ok(())
    }
}

impl Default for GlobTool { fn default() -> Self { Self::new() } }

#[async_trait]
impl Tool for GlobTool {
    fn name(&self) -> &'static str { "glob" }
    fn description(&self) -> &'static str {
        "Find files by glob pattern (e.g. \"**/*.rs\"). Returns matching paths relative to root, one per line."
    }
    fn schema(&self) -> serde_json::Value {
        serde_json::json!({
            "type": "object",
            "properties": {
                "pattern": { "type": "string", "description": "glob pattern" },
                "root": { "type": "string", "description": "directory to search (default: cwd)" }
            },
            "required": ["pattern"]
        })
    }
    async fn execute(&self, args: serde_json::Value) -> Result<String, ToolError> {
        let pattern = args["pattern"].as_str()
            .ok_or_else(|| ToolError::InvalidArgs("missing 'pattern'".into()))?;
        let root = args["root"].as_str().map(std::path::PathBuf::from)
            .unwrap_or_else(|| std::path::PathBuf::from("."));
        let matcher = Glob::new(pattern)
            .map_err(|e| ToolError::InvalidArgs(format!("bad glob: {e}")))?
            .compile_matcher();
        let mut matches = Vec::new();
        Self::walk(&root, &matcher, &mut matches)
            .map_err(|e| ToolError::Exec(format!("glob {pattern}: {e}")))?;
        matches.sort();
        if matches.is_empty() {
            Ok("no matches".into())
        } else {
            Ok(matches.join("\n"))
        }
    }
}
```

```rust
use crate::tool::{Tool, ToolError};
use async_trait::async_trait;
use grep_regex::RegexMatcher;
use grep_searcher::SearcherBuilder;
use grep_searcher::sinks::UTF8;
use std::path::Path;

const MAX_MATCHES: usize = 200;

pub struct GrepTool;

impl GrepTool {
    pub fn new() -> Self { Self }

    fn walk(root: &Path, files: &mut Vec<std::path::PathBuf>) -> std::io::Result<()> {
        for entry in std::fs::read_dir(root)? {
            let entry = entry?;
            let path = entry.path();
            if path.is_dir() {
                Self::walk(&path, files)?;
            } else {
                files.push(path);
            }
        }
        Ok(())
    }
}

impl Default for GrepTool { fn default() -> Self { Self::new() } }

#[async_trait]
impl Tool for GrepTool {
    fn name(&self) -> &'static str { "grep" }
    fn description(&self) -> &'static str {
        "Search file contents by regex. Returns `path:line:content` per match (max 200)."
    }
    fn schema(&self) -> serde_json::Value {
        serde_json::json!({
            "type": "object",
            "properties": {
                "pattern": { "type": "string", "description": "regex" },
                "root": { "type": "string", "description": "directory to search (default: cwd)" }
            },
            "required": ["pattern"]
        })
    }
    async fn execute(&self, args: serde_json::Value) -> Result<String, ToolError> {
        let pattern = args["pattern"].as_str()
            .ok_or_else(|| ToolError::InvalidArgs("missing 'pattern'".into()))?;
        let root = args["root"].as_str().map(std::path::PathBuf::from)
            .unwrap_or_else(|| std::path::PathBuf::from("."));
        let matcher = RegexMatcher::new(pattern)
            .map_err(|e| ToolError::InvalidArgs(format!("bad regex: {e}")))?;

        let mut files = Vec::new();
        Self::walk(&root, &mut files).map_err(|e| ToolError::Exec(e.to_string()))?;
        files.sort();

        let mut results: Vec<String> = Vec::new();
        'files: for file in files {
            let mut searcher = SearcherBuilder::new().build();
            let rel = file.strip_prefix(&root).unwrap_or(&file).to_string_lossy().into_owned();
            let mut per_file = Vec::new();
            let _ = searcher.search_path(&matcher, &file, UTF8(|line_no, line| {
                per_file.push(format!("{rel}:{line_no}:{}", line.trim_end()));
                Ok(results.len() + per_file.len() < MAX_MATCHES)  // 到上限即停
            }));
            results.extend(per_file);
            if results.len() >= MAX_MATCHES { break 'files; }
        }

        if results.is_empty() {
            Ok("no matches".into())
        } else {
            let mut out = results.join("\n");
            if results.len() >= MAX_MATCHES {
                out.push_str(&format!("\n... [truncated at {MAX_MATCHES} matches]"));
            }
            Ok(out)
        }
    }
}
```

```rust
use crate::gate::{PermissionGate, Prompt};
use crate::tool::{Tool, ToolError};
use async_trait::async_trait;
use std::time::Duration;

const DEFAULT_TIMEOUT: Duration = Duration::from_secs(120);
const HEAD_BYTES: usize = 30_000;
const TAIL_BYTES: usize = 30_000;

/// 只读命令白名单的首词。仅作"是否跳过确认"的提示，明确不是安全边界（DESIGN §6）。
const READ_ONLY: &[&str] = &[
    "ls", "cat", "head", "tail", "pwd", "echo", "which", "file", "stat",
    "grep", "rg", "find", "wc", "git", "date", "uname", "env", "id",
];

/// 粗分类：首个词在只读名单且命令不含 shell 复合/替换/重定向 → 视为只读。
/// 任何 `$(...)`、`&&`、`;`、`>`、`|`、反引号 都让它落到"需确认"。
/// 这是防手滑，不是安全边界——`bash -c`/`eval`/写脚本再执行都能绕过。
pub fn is_read_only(cmd: &str) -> bool {
    let cmd = cmd.trim();
    if cmd.contains("$(") || cmd.contains('`') || cmd.contains("&&")
        || cmd.contains("||") || cmd.contains(';') || cmd.contains('>')
        || cmd.contains('|') || cmd.contains("<") {
        return false;
    }
    match shell_words::split(cmd).ok().and_then(|w| w.first().cloned()) {
        Some(first) => READ_ONLY.contains(&first.as_str()),
        None => false,
    }
}

pub struct BashTool {
    gate: PermissionGate,
    timeout: Duration,
}

impl BashTool {
    pub fn new(gate: PermissionGate) -> Self {
        Self { gate, timeout: DEFAULT_TIMEOUT }
    }
    pub fn with_timeout(mut self, t: Duration) -> Self {
        self.timeout = t;
        self
    }

    fn truncate(s: &str) -> String {
        if s.len() <= HEAD_BYTES + TAIL_BYTES {
            return s.to_string();
        }
        let head = &s[..HEAD_BYTES];
        let tail = &s[s.len() - TAIL_BYTES..];
        let omitted = s.len() - HEAD_BYTES - TAIL_BYTES;
        format!("{head}\n... [omitted {omitted} bytes] ...\n{tail}")
    }
}

#[async_trait]
impl Tool for BashTool {
    fn name(&self) -> &'static str { "bash" }
    fn description(&self) -> &'static str {
        "Run a shell command. Times out after 120s. Long output is truncated keeping head and tail. Read-only commands (ls/cat/git status/...) may run without confirmation; anything else may prompt."
    }
    fn schema(&self) -> serde_json::Value {
        serde_json::json!({
            "type": "object",
            "properties": { "command": { "type": "string", "description": "shell command" } },
            "required": ["command"]
        })
    }
    async fn execute(&self, args: serde_json::Value) -> Result<String, ToolError> {
        let cmd = args["command"].as_str()
            .ok_or_else(|| ToolError::InvalidArgs("missing 'command'".into()))?;

        if !is_read_only(cmd) {
            self.gate.check(Prompt { tool: "bash", summary: format!("run: {cmd}") })?;
        }

        let child = tokio::process::Command::new("sh")
            .arg("-c").arg(cmd)
            .kill_on_drop(true)   // 关键：drop 时杀子进程，abort 不留孤儿
            .output();

        match tokio::time::timeout(self.timeout, child).await {
            Ok(Ok(out)) => {
                let mut text = String::new();
                text.push_str(&Self::truncate(&String::from_utf8_lossy(&out.stdout)));
                if !out.stderr.is_empty() {
                    text.push_str("\n[stderr]\n");
                    text.push_str(&Self::truncate(&String::from_utf8_lossy(&out.stderr)));
                }
                let code = out.status.code().map(|c| c.to_string())
                    .unwrap_or_else(|| "signal".into());
                text.push_str(&format!("\n[exit {code}]"));
                Ok(text)
            }
            Ok(Err(e)) => Err(ToolError::Exec(format!("spawn: {e}"))),
            Err(_) => Ok(format!("[timeout after {:?}: process killed]", self.timeout)),
        }
    }
}
```

```rust
// tools/mod.rs
pub mod bash;
pub mod edit;
pub mod glob;
pub mod grep;
pub mod read;
pub mod write;

use crate::gate::PermissionGate;
use crate::state::SessionState;
use crate::tool::ToolRegistry;

/// 装配 v0 全部 6 个工具。共享同一份 SessionState 与 PermissionGate。
pub fn register_all(state: SessionState, gate: PermissionGate) -> ToolRegistry {
    let mut reg = ToolRegistry::new();
    reg.register(Box::new(read::ReadTool::new(state.clone())));
    reg.register(Box::new(write::WriteTool::new(state.clone(), gate.clone())));
    reg.register(Box::new(edit::EditTool::new(state.clone(), gate.clone())));
    reg.register(Box::new(bash::BashTool::new(gate.clone())));
    reg.register(Box::new(glob::GlobTool::new()));
    reg.register(Box::new(grep::GrepTool::new()));
    reg
}
```
