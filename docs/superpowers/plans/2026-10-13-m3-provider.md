**Goal:** 实现 `OpenAiProvider`——用 reqwest+rustls 把 chat/completions 的 SSE 流接进 M1 的 `StreamAccumulator`，带 429/5xx 退避重试（仅在未产生内容前）、认证（环境变量 + auth.json）、以及传输层 wiremock 测试与 SSE fixture 解析测试。

**Architecture:** SSE 字节→`StreamEvent` 的转换是**独立纯函数 `parse_chunk`（不碰 IO）**，fixture 测试与 wiremock 测试共用。`OpenAiProvider` 只做三件事：发 HTTP、把 `bytes_stream()` 经 `eventsource-stream` 解成 `Event`、喂 `parse_chunk` → `StreamAccumulator`。retry 在 `complete()` 入口（未产生任何事件时）做；流一旦开始产生内容，中断即 `StreamEnd{Error}` 落盘不重试。认证只认 `CRAB_API_KEY`/`OPENAI_API_KEY` 环境变量 + `~/.crab/auth.json`。

```rust
/// 纯函数，不碰 IO —— fixture 测试与 provider 共用（Q13）。
/// OpenAI tool_call 流式偏差在此收敛：index 缺失、arguments 碎片、finish_reason 同帧。
```

**`ProviderError` 复用 M1**（`Network`/`Retryable`/`Aborted`），新增 variant `Api { status: u16, body: String }` 用于 4xx/上下文超长等不可重试错误。

**关键不变量**：
- `parse_chunk` 是纯函数，同一个 SSE 字节流喂给它和喂给真 provider 产出同样的 `StreamEvent` 序列。
- retry 只在 `complete()` 还没把任何事件 push 进 accumulator 之前发生。一旦第一个 `TextDelta`/`ToolUseStart` 进 accumulator，后续流中断只走 `StreamEnd{Error}`。
- `parse_chunk` 对 `data: [DONE]` 返回 `Ok(None)` 并标记流结束（由 provider 转为 `StreamEnd{EndTurn 或 ToolUse}`，取决于是否有 tool_call）。

```rust
use crate::provider::ProviderError;
use crate::stream::StreamEvent;
use crate::types::StopReason;

/// 单个 SSE data payload → StreamEvent。纯函数（Q13）。
pub fn parse_chunk(data: &str) -> Result<Option<StreamEvent>, ProviderError> {
    let data = data.trim();
    if data.is_empty() || data == "[DONE]" {
        return Ok(None);
    }
    let v: serde_json::Value = serde_json::from_str(data)
        .map_err(|e| ProviderError::Network(format!("bad SSE json: {e}: {data}")))?;
    let choice = &v["choices"][0];
    if choice.is_null() {
        return Ok(None);
    }
    // finish_reason 优先（有的 provider 与 content 同帧）
    if let Some(fr) = choice["finish_reason"].as_str() {
        let reason = match fr {
            "stop" => StopReason::EndTurn,
            "tool_calls" => StopReason::ToolUse,
            "length" => StopReason::MaxTokens,
            _ => StopReason::EndTurn,
        };
        return Ok(Some(StreamEvent::StreamEnd { reason }));
    }
    // 文本 delta
    if let Some(c) = choice["delta"]["content"].as_str() {
        if !c.is_empty() {
            return Ok(Some(StreamEvent::TextDelta(c.to_string())));
        }
    }
    // 其余（role 帧/空 delta/tool_call）后续 task 处理；本 task 返回 None
    Ok(None)
}
```

```rust
use crate::provider::ProviderError;
use crate::stream::StreamEvent;
use crate::types::StopReason;

/// 单个 SSE data payload → 0..n 个 StreamEvent。纯函数（Q13）。
/// 一个 chunk 可同时含文本 delta、多个 tool_call 分片、finish_reason。
pub fn parse_chunk(data: &str) -> Result<Vec<StreamEvent>, ProviderError> {
    let data = data.trim();
    if data.is_empty() || data == "[DONE]" {
        return Ok(Vec::new());
    }
    let v: serde_json::Value = serde_json::from_str(data)
        .map_err(|e| ProviderError::Network(format!("bad SSE json: {e}: {data}")))?;
    let choice = &v["choices"][0];
    if choice.is_null() {
        return Ok(Vec::new());
    }
    let mut out = Vec::new();
    let delta = &choice["delta"];

    // 文本
    if let Some(c) = delta["content"].as_str() {
        if !c.is_empty() {
            out.push(StreamEvent::TextDelta(c.to_string()));
        }
    }

    // tool_call 分片（可能多个）
    if let Some(tcs) = delta["tool_calls"].as_array() {
        for tc in tcs {
            let index = tc["index"].as_u64().unwrap_or(0) as usize;
            // 首片：有 id 和 function.name → ToolUseStart
            if let (Some(id), Some(name)) = (tc["id"].as_str(), tc["function"]["name"].as_str()) {
                out.push(StreamEvent::ToolUseStart {
                    index,
                    id: id.to_string(),
                    name: name.to_string(),
                });
            }
            // arguments 碎片 → ToolInputDelta（首片的空 arguments 不产生 delta）
            if let Some(args) = tc["function"]["arguments"].as_str() {
                if !args.is_empty() {
                    out.push(StreamEvent::ToolInputDelta {
                        index,
                        json_fragment: args.to_string(),
                    });
                }
            }
        }
    }

    // finish_reason 最后（可能与内容同帧）
    if let Some(fr) = choice["finish_reason"].as_str() {
        let reason = match fr {
            "stop" => StopReason::EndTurn,
            "tool_calls" => StopReason::ToolUse,
            "length" => StopReason::MaxTokens,
            _ => StopReason::EndTurn,
        };
        out.push(StreamEvent::StreamEnd { reason });
    }

    Ok(out)
}
```

```rust
use crab_core::provider::sse::parse_chunk;
use crab_core::stream::StreamAccumulator;
use crab_core::types::{ContentBlock, StopReason};

/// 把 SSE 字节流按帧切成 data payload（模拟 eventsource-stream 的输出）。
fn payloads(sse: &str) -> Vec<String> {
    sse.split("\n\n")
        .filter_map(|frame| {
            let line = frame.lines().find(|l| l.starts_with("data:"))?;
            Some(line.trim_start_matches("data:").trim().to_string())
        })
        .collect()
}

fn run_fixture(sse: &str) -> crab_core::types::AssistantTurn {
    let mut acc = StreamAccumulator::new();
    for p in payloads(sse) {
        for ev in parse_chunk(&p).unwrap() {
            acc.push(ev);
        }
    }
    acc.finish()
}
```

```rust
use crate::provider::{Provider, ProviderError, auth::Credentials, sse::parse_chunk};
use crate::stream::StreamAccumulator;
use crate::types::{AssistantTurn, Message, StopReason};
use async_trait::async_trait;
use eventsource_stream::Eventsource;
use futures::StreamExt;

pub struct OpenAiProvider {
    client: reqwest::Client,
    base_url: String,
    api_key: String,
    model: String,
    max_retries: u32,
}

impl OpenAiProvider {
    pub fn resolve() -> Result<Self, ProviderError> {
        let c = Credentials::resolve()?;
        Ok(Self::new(c.base_url, c.api_key, c.model))
    }

    pub fn new(base_url: impl Into<String>, api_key: impl Into<String>, model: impl Into<String>) -> Self {
        Self {
            client: reqwest::Client::new(),
            base_url: base_url.into(),
            api_key: api_key.into(),
            model: model.into(),
            max_retries: 3,
        }
    }

    pub fn with_max_retries(mut self, n: u32) -> Self {
        self.max_retries = n;
        self
    }

    fn request_body(&self, messages: &[Message]) -> serde_json::Value {
        let msgs: Vec<serde_json::Value> = messages.iter().map(message_to_openai).collect();
        serde_json::json!({
            "model": self.model,
            "messages": msgs,
            "stream": true,
        })
    }
}

/// 把内部 Message 映射成 OpenAI chat 消息形状。
fn message_to_openai(m: &Message) -> serde_json::Value {
    use crate::types::{ContentBlock, Role};
    let role = match m.role { Role::User => "user", Role::Assistant => "assistant" };
    // v0：文本与 tool_result 走 content；tool_use 走 tool_calls。先覆盖文本。
    let mut text = String::new();
    for b in &m.content {
        if let ContentBlock::Text { text: t } = b { text.push_str(t); }
    }
    serde_json::json!({ "role": role, "content": text })
}

#[async_trait]
impl Provider for OpenAiProvider {
    async fn complete(&self, messages: &[Message]) -> Result<AssistantTurn, ProviderError> {
        let url = format!("{}/chat/completions", self.base_url.trim_end_matches('/'));
        let resp = self.client
            .post(&url)
            .bearer_auth(&self.api_key)
            .json(&self.request_body(messages))
            .send()
            .await
            .map_err(|e| ProviderError::Network(format!("send: {e}")))?;

        let status = resp.status();
        if !status.is_success() {
            let body = resp.text().await.unwrap_or_default();
            return Err(ProviderError::Api { status: status.as_u16(), body });
        }

        let mut acc = StreamAccumulator::new();
        let mut stream = resp.bytes_stream().eventsource();
        while let Some(ev) = stream.next().await {
            match ev {
                Ok(event) => {
                    for se in parse_chunk(&event.data)? {
                        let is_end = matches!(se, StreamEvent::StreamEnd { .. });
                        acc.push(se);
                        if is_end { break; }
                    }
                }
                Err(e) => {
                    // 流中断：保留部分内容，以 Error 结束（不重试，Q13）
                    acc.push(StreamEvent::StreamEnd { reason: StopReason::Error });
                    let mut t = acc.finish();
                    t.interrupted = true;
                    return Ok(t);
                }
            }
        }
        Ok(acc.finish())
    }
}
```

- [ ] **Step 3: 加 retry 逻辑**——把 complete 包一层循环，仅在"还没发出请求/还没收到任何流内容"时重试 429/5xx

把 `complete` 拆成 `complete`（retry 循环）+ `complete_once`（单次尝试）。retry 只针对**响应前的 429/5xx 或网络错误**；一旦拿到 200 开始流式，流中断走 Error 不重试。

```rust
async fn complete(&self, messages: &[Message]) -> Result<AssistantTurn, ProviderError> {
    let mut attempt = 0;
    loop {
        match self.complete_once(messages).await {
            Ok(t) => return Ok(t),
            Err(ProviderError::Api { status, body }) if status == 429 || status >= 500 => {
                attempt += 1;
                if attempt > self.max_retries {
                    return Err(ProviderError::Retryable(format!(
                        "gave up after {} attempts: {} {}", self.max_retries, status, body
                    )));
                }
                let backoff = std::time::Duration::from_millis(100 * 2u64.pow(attempt - 1));
                tokio::time::sleep(backoff).await;
            }
            Err(ProviderError::Network(e)) => {
                // 连接失败（未产生内容）也可重试
                attempt += 1;
                if attempt > self.max_retries {
                    return Err(ProviderError::Retryable(format!("gave up: {e}")));
                }
                tokio::time::sleep(std::time::Duration::from_millis(100 * 2u64.pow(attempt - 1))).await;
            }
            Err(e) => return Err(e),
        }
    }
}
```

`complete_once` = 原 complete 的主体（发请求 + 流式）。流式中出错已在 complete_once 内返回 `Ok(interrupted turn)`，不会进 retry 分支——这保证"已开始就不重试"。

```rust
fn messages_to_openai(m: &Message) -> Vec<serde_json::Value> {
    use crate::types::{ContentBlock, Role};
    let mut out = Vec::new();
    let role = match m.role { Role::User => "user", Role::Assistant => "assistant" };

    let mut text = String::new();
    let mut tool_calls = Vec::new();
    for b in &m.content {
        match b {
            ContentBlock::Text { text: t } => text.push_str(t),
            ContentBlock::ToolUse { id, name, input } => {
                tool_calls.push(serde_json::json!({
                    "id": id, "type": "function",
                    "function": { "name": name, "arguments": input.to_string() }
                }));
            }
            ContentBlock::ToolResult { tool_use_id, content, .. } => {
                // tool_result 独立成 role:tool 消息
                out.push(serde_json::json!({
                    "role": "tool", "tool_call_id": tool_use_id, "content": content
                }));
            }
        }
    }

    // assistant/user 的文本 + tool_calls 合成一条（除非纯 tool_result）
    if !text.is_empty() || !tool_calls.is_empty() || out.is_empty() {
        let mut msg = serde_json::json!({ "role": role });
        if !text.is_empty() { msg["content"] = serde_json::Value::String(text); }
        if !tool_calls.is_empty() { msg["tool_calls"] = serde_json::Value::Array(tool_calls); }
        if msg.get("content").is_none() && msg.get("tool_calls").is_none() {
            msg["content"] = serde_json::Value::String(String::new());
        }
        // assistant 带 tool_calls 时 content 可为 null
        out.insert(0, msg);
    }
    out
}
```

**已知坑（给执行者）**：
- cargo 需代理。
- **eventsource-stream 的 `Eventsource` trait 要求 `Stream<Item=Result<AsRef<[u8]>>>`**；reqwest 的 `bytes_stream()` 产出 `Result<Bytes, reqwest::Error>`，`Bytes: AsRef<[u8]>`，直接 `.eventsource()` 可用，但要 `use eventsource_stream::Eventsource` 和 `futures::StreamExt`。
- `Event.data` 是 `String`（已解好 UTF-8），喂 `parse_chunk(&event.data)`。
- wiremock 的自定义 `Respond` 用于"前两次 429 第三次 200"——`ResponseTemplate` 无法表达序列，必须实现 `Respond` trait。需 `use wiremock::{Respond, Request}`。
- SSE fixture 的 `data:` 帧之间要有空行（`\n\n`），`[DONE]` 也是一帧。
- wiremock `insert_header("content-type", "text/event-stream")` 必须有，否则 eventsource-stream 可能按普通 body 处理。
- 多字 arguments JSON 在 fixture 字符串里的转义最容易写错（`{\"path\":\"x\"}` 嵌在 Rust format! 里是 `\\\"`）。Task 8 的 TwoTurn 用 format! 拼 target 路径，转义层级深——出错就先单独 println fixture 验证。
- 环境变量测试串行跑（`std::env::set_var` 有竞态），用 `--test-threads=1` 或每个测试清理。Task 4 的测试共享环境变量，若并发 flaky，给测试加串行化（`serial_test` crate 或合并为单测试）。

**执行者注意的两处签名演进（有意，非 bug）**：Task 1→2 `parse_chunk` 从 `Option` 变 `Vec`；Task 5→7 `message_to_openai` 从单值变 `Vec` + 改名 `messages_to_openai`。按 task 顺序执行时这些是有序重构。
