# M4 CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 crab 装上终端：`crab --print "..."`（一次性，可脚本化）、交互模式（reedline 输入 + crossterm 流式打印 token）、`--continue` 恢复会话、权限确认 UI、`AGENTS.md` 加载、Ctrl-C 中断 agent。做完即可手工试用 + dogfood。

**Architecture:** `crab-cli` 持有全部终端依赖（clap/crossterm/reedline），`crab-core` 保持无终端。流式 delta 透传：`Provider::complete` 加可选 `on_event: Option<&broadcast::Sender<StreamEvent>>`，provider 边解析 SSE 边实时推 `StreamEvent`，agent 桥接成 `AgentEvent::TextDelta`（解决 M1 遗留，DESIGN §239）。交互线程模型：reedline 在 `spawn_blocking`（它同步阻塞），agent 在 tokio task，Ctrl-C 经 `tokio::signal::ctrl_c` 调 `agent.abort()`。权限确认 UI 在 cli 层实现 `Confirmer` 回调（core 的 `PermissionGate::with_confirmer`），--print 用 auto_approve、交互用终端确认。

**Tech Stack:** clap 4 derive、reedline 0.52（`Reedline::create` + `read_line(&dyn Prompt) -> Signal`）、crossterm 0.29、tokio（signal/process/task）、assert_cmd 2.2 + tempfile（dev，端到端 CLI 测试）。

**前置状态（已存在，勿重建）：** `crab-core` 有完整 `Agent`（`run`/`subscribe`/`abort`/`AgentEvent`）、`OpenAiProvider`（`resolve()`/`new`）、`Credentials`、`register_all(SessionState, PermissionGate)`、`Session::create/load`（--continue）、`ToolRegistry::schemas`。`crab-cli` 现在只有 `main(){ println! }`。红线：crab-core 无终端 crate、无 println!。cargo 需代理。

**本计划范围：** M4 全部。M5 dogfood 另行。

**M4 完成标志（DESIGN §12）：** `crab --print "..."` 连真模型跑出文本并流式打印；交互模式能多轮对话 + 工具调用 + 权限确认 + Ctrl-C 中断；`--continue` 恢复上次会话；`AGENTS.md` 内容进 system prompt；`assert_cmd` 端到端测试（用 MockProvider）全绿；crab-core 红线不破。

```rust
use anyhow::{Context, Result};
use crab_core::agent::{Agent, AgentConfig};
use crab_core::gate::PermissionGate;
use crab_core::provider::openai::OpenAiProvider;
use crab_core::session::Session;
use crab_core::state::SessionState;
use crab_core::tools::register_all;
use std::path::{Path, PathBuf};

pub const BASE_PROMPT: &str = "You are crab, a coding agent. Use the provided tools to read, edit, and run code. Be precise. When editing, match exact text.";

pub struct AppConfig {
    pub yolo: bool,
    pub system: Option<String>,
    pub provider: String,
}

pub fn build_system_prompt(cwd: &Path, extra: Option<String>) -> String {
    let mut sp = String::from(BASE_PROMPT);
    let agents = cwd.join("AGENTS.md");
    if let Ok(content) = std::fs::read_to_string(&agents) {
        sp.push_str("\n\n# Project instructions (AGENTS.md)\n");
        sp.push_str(&content);
    }
    if let Some(e) = extra {
        sp.push_str("\n\n# Additional instructions\n");
        sp.push_str(&e);
    }
    sp
}

fn sessions_dir(cwd: &Path) -> PathBuf {
    cwd.join(".crab").join("sessions")
}

pub fn build_agent(cfg: &AppConfig, continue_: bool) -> Result<(Agent, String)> {
    let cwd = std::env::current_dir().context("cwd")?;
    let system_prompt = build_system_prompt(&cwd, cfg.system.clone());

    let provider: Box<dyn crab_core::provider::Provider> = match cfg.provider.as_str() {
        "mock" => Box::new(crab_core::provider::MockProvider::new(vec![])),
        _ => Box::new(OpenAiProvider::resolve().map_err(|e| anyhow::anyhow!("{e}"))?),
    };

    let gate = if cfg.yolo { PermissionGate::yolo() } else { PermissionGate::auto_approve() };
    let tools = register_all(SessionState::default(), gate);

    let dir = sessions_dir(&cwd);
    let session = if continue_ {
        let latest = latest_session(&dir).context("no prior session to continue")?;
        Session::load(&latest).with_context(|| format!("load {}", latest.display()))?
    } else {
        Session::create(&dir).context("create session")?
    };

    let agent = Agent::new(provider, tools, session, AgentConfig { max_turns: 50 });
    Ok((agent, system_prompt))
}

fn latest_session(dir: &Path) -> Option<PathBuf> {
    let mut files: Vec<PathBuf> = std::fs::read_dir(dir).ok()?
        .filter_map(|e| e.ok().map(|e| e.path()))
        .filter(|p| p.extension().is_some_and(|x| x == "jsonl"))
        .collect();
    files.sort();
    files.pop()
}
```

```rust
use anyhow::Result;
use reedline::{DefaultPrompt, Reedline, Signal};
use crate::app::{AppConfig, build_agent};
use crate::render::render_events;

#[derive(Debug, PartialEq)]
pub enum Input { Quit, Skip, Message(String) }

pub fn classify(s: &str) -> Input {
    let t = s.trim();
    match t {
        "/quit" | "/exit" => Input::Quit,
        "" => Input::Skip,
        _ => Input::Message(t.to_string()),
    }
}

pub async fn run_interactive(cfg: &AppConfig, continue_: bool) -> Result<()> {
    let (mut agent, _sys) = build_agent(cfg, continue_)?;
    let mut rl = Reedline::create();
    let prompt = DefaultPrompt::default();
    println!("crab interactive. /quit to exit, Ctrl-C to abort a run.");

    loop {
        // reedline read_line is blocking → spawn_blocking
        let line = tokio::task::spawn_blocking({
            let mut rl = std::mem::replace(&mut rl, Reedline::create());
            let prompt = prompt.clone();
            move || {
                let sig = rl.read_line(&prompt);
                (rl, sig)
            }
        }).await??;

        // 拿回 rl（spawn_blocking 返回）
        // 注：Reedline 不能跨 await 持有，故每次 move 进出
        rl = line.0;
        match line.1 {
            Ok(Signal::Success(text)) => match classify(&text) {
                Input::Quit => break,
                Input::Skip => continue,
                Input::Message(m) => {
                    let rx = agent.subscribe();
                    let render = tokio::spawn(render_events(rx));
                    let abort = agent_abort_handle(&agent);
                    // Ctrl-C during run aborts the agent
                    let run = agent.run(m);
                    tokio::pin!(run);
                    tokio::select! {
                        r = &mut run => { let _ = r?; }
                        _ = tokio::signal::ctrl_c() => { abort.cancel(); let _ = run.await; }
                    }
                    let _ = render.await;
                }
            },
            Ok(Signal::CtrlC) => continue,       // 编辑行内 Ctrl-C：清行继续
            Ok(Signal::CtrlD) => break,           // EOF：退出
            _ => continue,
        }
    }
    Ok(())
}

fn agent_abort_handle(agent: &crab_core::agent::Agent) -> tokio_util::sync::CancellationToken {
    // 需要 agent 暴露 abort token；M1 有 abort() 方法但需 &self。
    // 若 Agent 不暴露可克隆的 token，这里改为 agent 暴露 `abort_handle()`。
    agent.abort_token()
}
```

**⚠️ 需要的 core 改动**：`Agent` 要暴露一个可克隆的 `CancellationToken`（M1 的 `abort()` 拿 `&self`，但交互里 run 借走 `&mut self`，没法同时调 `abort()`）。给 `Agent` 加 `pub fn abort_token(&self) -> CancellationToken { self.abort.clone() }`。这是 core 的小改，需测试。

```rust
use crab_core::gate::{Decision, Prompt};
use std::io::Write;

pub fn parse_answer(s: &str) -> Option<Decision> {
    match s.trim().to_lowercase().as_str() {
        "y" | "yes" => Some(Decision::Allow),
        "n" | "no" => Some(Decision::Deny),
        "a" | "all" => Some(Decision::AllowAll),
        _ => None,
    }
}

pub fn terminal_confirmer() -> crab_core::gate::Confirmer {
    std::sync::Arc::new(|p: Prompt| {
        loop {
            print!("\n⚠ {} — {} \nallow? [y]es/[n]o/[a]ll: ", p.tool, p.summary);
            let _ = std::io::stdout().flush();
            let mut line = String::new();
            if std::io::stdin().read_line(&mut line).is_err() { return Decision::Deny; }
            if let Some(d) = parse_answer(&line) { return d; }
            println!("please answer y, n, or a");
        }
    })
}
```
